1. Introduction                                        *codediff-introduction*

codediff.nvim renders diffs computed by the external `codediff` CLI
(https://github.com/ivankovic/codediff) directly in Neovim buffers, using
`codediff --mode json` for full-range-precision hunk data instead of parsing
ANSI text back out of a terminal-based diff tool.

==============================================================================
2. Requirements                                        *codediff-requirements*

* Neovim >= 0.10 (uses |vim.system()|).
* The `codediff` binary, on $PATH or pointed at explicitly (see
  |codediff-setup|), built with `--mode json` support. Run `:checkhealth
  codediff` to confirm both.

==============================================================================
3. Setup                                                      *codediff-setup*

>lua
    require('codediff').setup({
      -- Path to (or name of) the codediff binary. Default: 'codediff'.
      bin = 'codediff',
    })
<
`setup()` is optional - the defaults above are used if it is never called.

==============================================================================
4. Commands                                                *codediff-commands*

                                                                  *:CodeDiff*
:CodeDiff {before} {after}
    Diff two files and open them side by side in a new tab, each side
    highlighted with its own changes.

                                                              *:CodeDiffThis*
:CodeDiffThis
    Diff the current buffer's unsaved edits against the on-disk file. Does
    nothing (with a message) if the buffer has no unsaved changes.

==============================================================================
5. Highlights                                            *codediff-highlights*

codediff.nvim defines these highlight groups, linked (not hardcoded) to
standard diff highlights, so any colorscheme that already styles the
standard groups looks right immediately:

    CodeDiffInsert  -> DiffAdd
    CodeDiffDelete  -> DiffDelete
    CodeDiffUpdate  -> DiffChange
    CodeDiffMove    -> DiffText

Override any of them as you would any other highlight group, e.g.:
>lua
    vim.api.nvim_set_hl(0, 'CodeDiffMove', { fg = '#e5c07b' })
<
